# Recursos del curso de Unreal Engine con Blueprints

Recursos descargables del [libro universitario de Unreal Engine con Blueprints](https://elloza.com/teachbook_unreal_engine_bp/), de Álvaro Lozano Murciego (Universidad de Salamanca).

## Third Person con Starter Content para UE 5.8

[Descargar el proyecto inicial (ZIP, 921 MiB)](https://github.com/elloza/teachbook_unreal_engine_resources/releases/download/ue58-starter-v1/Adventure3D_UE58_StarterContent_v1.zip)

[Instrucciones en español](https://elloza.com/teachbook_unreal_engine_bp/es/90_anexos/versiones_ue.html#starter-content-en-ue-5-8) · [English instructions](https://elloza.com/teachbook_unreal_engine_bp/en/90_annexes/ue_versions.html#starter-content-in-ue-5-8) · [Release y SHA-256](https://github.com/elloza/teachbook_unreal_engine_resources/releases/tag/ue58-starter-v1)

Es una **base de trabajo editable**, comprobada en UE 5.8.2 para Windows. Incluye la plantilla Third Person del aula adaptada y Starter Content completo, a partir de las plantillas y muestras de Epic de UE 5.1.1. No incluye el juego resuelto del docente, el motor ni assets de terceros de Fab/Marketplace.

Los assets de Epic conservan su [licencia de Unreal Engine](https://www.unrealengine.com/eula/unreal); no se les aplica la licencia CC BY del libro. Consulta los README y NOTICE dentro del ZIP.

## English

Downloadable resources for the [Unreal Engine with Blueprints university course book](https://elloza.com/teachbook_unreal_engine_bp/).

The release provides an **editable starting point**, checked in UE 5.8.2 on Windows: the adapted classroom Third Person template and full Starter Content, based on Epic's UE 5.1.1 templates and samples. It does not include the instructor's completed game, engine binaries or third-party Fab/Marketplace assets.

Epic's assets retain their [Unreal Engine licence](https://www.unrealengine.com/eula/unreal), not the book's CC BY licence. Read the README and NOTICE included in the ZIP.
